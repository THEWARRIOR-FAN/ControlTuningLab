# 自动化控制实验文件夹介绍

## 概述

本文件夹用于存放基于网页技术实现的各类控制系统仿真实验，旨在通过交互式网页界面帮助理解和掌握不同控制模型的工作原理和参数调节方法。

> **文档约定**：预设参数表、预期现象实测数值、参数/滑块范围与物理模型细节**只写在各实验的 `README.md` 里**（单一权威），本文件只做系列导览。页面文案携带相同数字，由 `tests/docs-sync.test.cjs` 自动校验。

## 当前实验

### 水位调参实验

**入口**：`experiments/water-tuner/index.html`　**详细说明**：[`experiments/water-tuner/README.md`](../experiments/water-tuner/README.md)

**实验目的**：直观理解 PID 控制器的工作原理，掌握 PID 参数（Kp、Ki、Kd）对系统性能的影响。

**功能特点**：
- 实时水位模拟与可视化，目标水位可调
- 核心指标区：当前液位、目标液位、误差、实际阀位四个关键量放大显示
- PID 公式卡：P/I/D 每项单独一行，代入当前误差、参数、水位速度的真实数值并标色，末行显示限幅与“延迟→实际阀位”路径
- 进出水平衡提示：显示净进/净出/平衡状态，帮助理解稳态
- 实验预设附带预期现象，便于带着问题观察
- 实时曲线可暂停回看任意历史时段；仿真时间、存水、理论静差、累计溢流等次要数据默认折叠
- 物理模型说明收入左侧折叠区，调参小贴士轮播均为本模型实测结论

**使用方法**：
1. 打开 `experiments/water-tuner/index.html` 文件
2. 从 `Ki=0`、`Kd=0` 开始逐步调节 `Kp`，观察响应速度、静差和振荡；之后逐步加入 `Ki`，最后才尝试 `Kd`
3. 调节参数时每次只改一个，并观察右侧水池状态、实时曲线和各项读数。滑块范围只是本仿真的操作边界，不是现实中已知的整定答案
4. 目标水位、Kp/Ki/Kd 各自的含义与滑块范围见实验 README；实际参数和单位始终在「PID 拆解」中显示
5. 对照「PID 公式卡」，理解 P/I/D 各项代入的数字如何相加、限幅并经过延迟变成实际阀位
6. 暂停状态下拖动曲线下方的回看滑块，可回看任意历史时段；点击“重置实验”清空曲线并恢复初始状态

### 调温模型实验

**入口**：`experiments/temp-tuner/index.html`　**详细说明**：[`experiments/temp-tuner/README.md`](../experiments/temp-tuner/README.md)

**实验目的**：在温度对象上复现 P/I/D 的典型现象——纯 P 偏大会超调并来回振荡、偏小则加热慢且留大静差；I 太大振荡加剧、合适则误差消失；D 用于微调，减少超调和波动。

**功能特点**：
- 实时水温模拟与可视化：大锅烧水动画，锅内水量固定；温度越高气泡越多、水色越暖、蒸汽越明显，锅底火光与火苗跟随实际功率
- 锅内红色目标线与橙色虚线分别标出目标与实际水温的高度；锅下温度条填充 = 实际水温，红色为目标刻度、蓝色为测量刻度，水温贴住目标（±0.5 °C）时整条变绿
- 核心指标区：当前水温、目标温度、误差、加热管开度四个关键量放大显示
- PID 公式卡：P/I/D 每项单独一行，代入当前误差、参数、升温速度的真实数值并标色，末行显示限幅与“延迟→实际功率”路径
- 加热/散热平衡提示：显示净加热/净散热/热平衡状态，帮助理解稳态
- 双曲线对比：蓝实线测量温度、橙虚线实际水温，直接看见传感器惯性造成的滞后；曲线纵轴带 0–100 °C 刻度，与 5 等分网格对齐
- 六组实验预设附带预期现象，便于带着问题观察
- 调参小贴士轮播，均为本模型实测结论

**使用方法**：
1. 打开 `experiments/temp-tuner/index.html` 文件
2. 从「P 偏小 / P 合适 / P 偏大」三组预设观察静差与振荡，再用「PI 合适 / I 过大」观察积分作用，最后用「PID 微调」对比 D 的效果
3. 调节参数时每次只改一个，并观察右侧温度响应（大锅内的目标/实际温度线、气泡密度与锅下温度条）、实时曲线和公式卡读数。滑块范围只是本仿真的操作边界，不是现实中已知的整定答案
4. 各滑块的含义、范围与内部映射见实验 README；实际参数始终在「PID 拆解」中显示
5. 对照「PID 公式卡」，理解 P/I/D 各项代入的数字如何相加、限幅并经过延迟变成实际加热功率
6. 暂停状态下拖动曲线下方的回看滑块，可回看任意历史时段；点击“重置实验”清空曲线并恢复冷态

## 技术实现

所有实验均采用纯前端技术实现，无需后端服务器，可直接在浏览器中打开运行：

- HTML5 结构 + CSS3 样式 + JavaScript 逻辑 + Canvas API 数据可视化
- 零依赖、零构建：每个实验页只按顺序加载 `core/` 共享脚本与本实验的 `model.js`（仿真模型，不碰 DOM）和 `ui.js`（界面）
- 仿真为固定物理步长推进，与显示帧率无关；界面时间始终是仿真秒

**验证**（需 Node.js，无第三方依赖）：

```bash
node --test "tests/*.test.cjs"
```

测试用共享脚手架 `tests/helpers/harness.cjs` 在 vm 中按浏览器顺序加载脚本；`tests/docs-sync.test.cjs` 额外校验文档与页面文案的数字一致。各实验的测试项数与覆盖范围见对应 README。

## 实验价值

通过这些仿真实验，可以：
- 直观理解各种控制算法的工作原理
- 掌握参数调节对系统性能的影响
- 比较不同控制策略的优缺点
- 培养控制系统设计和调试能力
- 为实际工程应用提供参考
